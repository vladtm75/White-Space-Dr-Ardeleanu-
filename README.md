# White Space - Dr. Ardeleanu

Plan de expansiune, 8 septembrie 2026. Harta interactivă și PDF-ul includ 22 de orașe White Space, 13 deschideri noi și ținta de 25 de clinici în 2030.

## Publicare pe GitHub Pages
1. Încarcă fișierele din acest folder în rădăcina repository-ului ales, păstrând index.html și PDF-ul împreună.
2. În Settings > Pages, selectează Deploy from a branch, apoi branch-ul main și / (root). Salvează.
3. După publicare, copiază adresa afișată în Settings > Pages. Aceasta este adresa de pus în email, nu adresa fișierului HTML din repository.

Documentație: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Harta și datele sunt incluse în HTML. Fontul Poppins se încarcă din Google Fonts; fără conexiune se folosește Arial. Nu este necesar un proces de build. PDF-ul are fonturile încorporate.

O pagină GitHub Pages obișnuită este publică: persoanele care au acces la adresă pot consulta planul.
